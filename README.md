# Fleet & Fuel Management System Design

Software Design & Architecture coursework at FAST NUCES. This repository contains requirements documents and UML models for university fleet fuel workflows. It is design documentation, not a deployed application.

## Contents

- `Fuel Management System_Usecase Diagram _FR_NFR.odt`: use cases and functional/nonfunctional requirements.
- `Fuel Management System_UML Diagrams.odt`: UML source documentation.
- `docs/diagrams/`: use-case, class, sequence, state-machine and activity diagram images.

Open ODT files in LibreOffice or another compatible reader. No application build or deployment is available. Availability/security targets in requirements describe proposed behavior, not measured operational guarantees. No implemented GPS telemetry, route-dispatch system or verified use of named design patterns is claimed.
